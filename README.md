# Pídelo de España

Landing page de Pídelo de España, un servicio para recibir, consolidar y preparar compras realizadas en tiendas españolas para su envío puerta a puerta a Caracas.

## Estado

Primera versión de validación. Los botones de WhatsApp están preparados visualmente y permanecerán desactivados hasta disponer del número de atención.

## Desarrollo

```bash
pnpm install
pnpm dev
```

La aplicación estará disponible en `http://localhost:3000`.

## Validación

```bash
pnpm build
```
